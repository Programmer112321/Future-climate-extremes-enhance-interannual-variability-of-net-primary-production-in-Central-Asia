This repository contains the R code used to produce the results and figures in:

> **Chu, D., Zhang, L., Wu, H., He, H., & Ren, X. (2026).** Future climate extremes enhance interannual variability of net primary production in Central Asia. *Environmental Research Letters.* https://doi.org/10.1088/1748-9326/ae6dd4

## Overview

Central Asia's arid and semi-arid ecosystems are highly sensitive to climate variability. This study uses CMIP6 multi-model projections under multiple emission scenarios (SSP126, SSP585) to investigate how intensifying climate extremes — droughts, heatwaves, anomalous wet periods, and compound events — will amplify the interannual variability (IAV) of net primary production (NPP) throughout the 21st century.

**Key findings:**
- Future climate extremes significantly increase the year-to-year swings in NPP across Central Asia
- Compound dry-hot events are the dominant driver of extreme negative NPP anomalies
- The amplification effect is strongest under the high-emission scenario (SSP585)
- Spatial heterogeneity exists across sub-regions (northern, central, southwestern, and southeastern Central Asia)

## Repository Structure

```
├── 0_sensitivy_analysis_detrend.R    # Sensitivity test: linear vs LOESS vs polynomial detrending
├── 0_sensitivy_analysis_climate.R    # Sensitivity test: growing-season vs full-year climate
├── 1_threshold_identify.R            # Compute IAV quantile thresholds (5th/10th/90th/95th percentiles)
├── 2_main_analysis_gross.R           # Main analysis: correlations, sensitivity, attribution
├── 2_main_anlysis_density.qmd        # Density-based IAV analysis (Quarto)
├── 3_plot.qmd                        # Figure generation (Quarto)
├── INPUT/
│   └── climate+dem+lucc+npp+bound/
│       └── bound.shp                 # Central Asia boundary shapefile (4 sub-regions)
├── rdata/                            # Processed analysis outputs (.RData)
└── datatable/                        # Intermediate CSV tables (generated by scripts)
```

> **Note:** Raw CMIP6 climate and NPP input data are not included due to file size. See [Data Sources](#data-sources) below.

## Workflow

Run the scripts in the following order:

### Step 0 — Sensitivity analyses (optional but recommended)
```r
source("0_sensitivy_analysis_detrend.R")   # Tests linear, LOESS, and polynomial detrending
source("0_sensitivy_analysis_climate.R")   # Compares growing-season vs full-year climate signals
```
These scripts validate that the main results are robust to methodological choices.

### Step 1 — Compute IAV thresholds
```r
source("1_threshold_identify.R")
```
Reads detrended NPP and climate anomaly tables, computes 5th/10th/90th/95th percentile thresholds per pixel/model/scenario, and writes `datatable/ca_threshold_density.csv` and `datatable/ca_threshold_gross.csv`.

### Step 2 — Main analysis
```r
source("2_main_analysis_gross.R")
```
Performs:
- **Spatial correlation** — Pearson correlation between climate IAV and NPP IAV at each pixel
- **Climate sensitivity** — Pixel-level linear regression of NPP on temperature (`tas`) and precipitation (`pr`)
- **Spatial contribution** — How much each pixel contributes to the regional total NPP anomaly
- **Extreme event attribution** — Decomposition of NPP extremes into dry, wet, hot, cold, and compound dry-hot events
- **Zonal analysis** — Aggregation across the four Central Asia sub-regions

Outputs are saved to `rdata/ca_gross.RData` and `rdata/ca_gross_space_relationship.RData`.

Run `2_main_anlysis_density.qmd` for the density-weighted version of the same analysis.

### Step 3 — Generate figures
Open and render `3_plot.qmd` in RStudio to reproduce all manuscript figures.

## Requirements

**R (≥ 4.1)** with the following packages:

```r
install.packages(c(
  "data.table",   # fast data processing
  "tidyverse",    # data wrangling and ggplot2
  "terra",        # raster operations and zonal statistics
  "broom",        # tidy model outputs
  "ggpubr",       # correlation annotations on plots

))
```
